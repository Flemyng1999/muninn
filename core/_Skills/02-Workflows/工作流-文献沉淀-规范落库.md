# 工作流-文献沉淀-规范落库

正式投喂入口：[[_Skills/02-Workflows/工作流-文献沉淀-规范落库-正式提示词]]

> [!abstract]- 适用场景
> 你把论文阅读记录、摘要、截图摘录、方法总结或自己的判断发给 AI，要求它沉淀到 01-Literature，并补齐与项目、卡片、相关文献之间的关联。

## 依赖读取顺序

1. 先读取 frontmatter 中的 `linked_role`、`required_blocks`、`related_templates`、`entry_prompt`。
2. 再读取当前正文中的文献沉淀规则与执行步骤。
3. 若要真正投喂模型，优先进入 `entry_prompt` 指向的正式提示词页。
4. 补齐方法依赖后，再去读取 `target_folders`、`scope_paths` 对应的业务文件。
5. 默认先读目标文献页、相关项目页和最关键的对照文献 / 卡片，不先全库扩散。

## 输入类型

1. 论文题录信息。
2. 阅读笔记、摘要、摘录、截图说明。
3. 方法总结、价值判断、复用点。
4. 与项目、卡片或已有文献的对照关系。

## 核心规则

1. 按 [[_Templates/文献笔记模板]] 的结构写入。
2. 用自己的话写清问题、方法、价值与一句话判断，不做摘抄堆砌。
3. 补全 `topics`、`methods`、`one_sentence`、`related_projects` 等关键字段。
4. 补上与项目、支撑卡片、对照文献之间的关联。
5. 若文献直接支撑某项目方向，应同步更新相关项目页或指出需要联动的位置。

## 执行步骤

1. 先识别题录和文献核心信息。
2. 生成或更新 01-Literature 下的规范文献页。
3. 提炼“一句话判断”“为什么值得读”“可直接复用的内容”“我的判断”。
4. 扫描工作区中已有项目、卡片、文献，补最关键的双链。
5. 如文献已形成稳定知识，指出适合新增或更新的卡片主题。

## 输出

1. 生成或更新文献页。
2. 汇报本次补全的字段和关联。
3. 指出可继续卡片化的主题或暂不卡片化的原因。

## 成功标准

1. 文献页足够详细、规范、可复用。
2. 页面不是摘抄仓库，而是以后还能直接使用的入口页。
3. 文献能从项目、卡片、相关文献网络中被反查回来。

## 禁止事项

1. 不只复制摘要或原文摘录。
2. 不遗漏关键字段与关联。
3. 不把文献页写成与会议页相同的流水结构。
