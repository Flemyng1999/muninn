# 组件索引

> [!abstract]- 组件索引说明
> 这里存放可拼接的 prompt 片段，例如输出面板、禁止事项、评审清单、质量阈值。

## 收录标准

1. 片段可以被多个角色或工作流复用。
2. 片段本身足够独立，不依赖单一场景才能成立。
3. 优先沉淀“格式约束”和“质量检查”，它们最容易跨任务复用。

## 命名格式

`组件-用途-约束.md`
