# 实验-E1-野外工具识别率

## 假设

基于 SlowFast (Feichtenhofer 2019) 视频特征 + 姿态骨架分支的融合 pipeline，能在**野外未见过的摄像机位**识别 [[概念-工具使用定义]] 事件，**F1 ≥ 0.85**。

## 方法

1. **训练集**：2024-04 ~ 2025-12 共 180 小时视频，8,400 事件（60% 正例 / 40% 负例）
2. **验证集**：2025-01 独立摄像机位，500 段（两标注员双盲）
3. **pipeline**：
   - SlowFast 提取视频特征
   - HRNet 提取 8 关键点骨架
   - MLP 融合头输出事件概率
4. **训练**：8×A100，12 小时，early stopping on val F1

## 判据

按 [[概念-Gateα-工具识别准确率]]：
- F1 ≥ 0.85 + P ≥ 0.80 + R ≥ 0.80 + κ ≥ 0.75

## 结果

- **Precision = 0.87** ✅
- **Recall = 0.84** ✅
- **F1 = 0.855** ✅
- **κ = 0.79**（标注员间一致性，验证集本身可信） ✅

**四项全过 → Gate α PASS**（2026-03-25 宣告，详见 [[_Governance/CHANGELOG]]）

## 边界 / 局限

1. **摄像机位泛化**：验证集仅东京 2 个机位，柏林机位未测（Gate γ 工作）
2. **罕见工具类**：meta-tool 事件（> 1 步工具序列）训练样本 < 50，单独评估 F1 仅 0.61（[[03-Zettelkasten/思考-罕见类长尾]]，待建 seedling）
3. **光照条件**：夜间 / 黎明视频 F1 下降到 0.73，本项目主流程只用日间 06:00-18:00 视频
