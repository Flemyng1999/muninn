# 思考-个体差异vs种群差异

## 问题起点

读 [[洞察-城市化压力驱动工具创新]] 时意识到：说"城市化压力驱动工具创新"是**种群层**陈述；但证据（UAI 与 SLI 正相关）来自**个体层**数据。

这两层在统计推断上是**不能混用**的（Robinson 1950 生态谬误；Simpson 1951 悖论）。

## 展开

### 种群层问题形如：
"在种群 P1（城市化高）中，工具使用频率 f(P1) 比种群 P2 高。"
→ 需要 P1 / P2 两个**独立**种群作比较

### 个体层问题形如：
"在单一种群 P 内，UAI 高的个体比 UAI 低的个体 SLI 更高。"
→ 只需 P 内个体变异

本项目 2026-04 证据**全部是个体层**（东京一个种群内 152 只鸟）。不能直接推出种群层结论。

## 应对策略

**短期（Gate β 内）**：把结论严格写成个体层语句——"UAI 高的个体 SLI 高"。

**中期（Gate γ）**：跨城市（柏林 / 上海 / 东京）比较，才能得到种群层证据。

**方法学约束**：即使 Gate γ 完成，也要做：
1. **multi-level modeling**：种群 ID 作随机效应
2. **sensitivity analysis**：对"个体 → 种群"的结论如何稳定？

## 更一般的原则

**永远问：我这个结论是哪个层级的？证据是哪个层级的？它们匹配吗？**

这和我在其他项目学到的 [[概念-现象与尺度对齐]]（若此卡存在）完全同构，是跨领域的方法学警戒。
