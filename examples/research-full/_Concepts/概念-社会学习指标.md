# 概念-社会学习指标

## 定义

**社会学习指标**（Social Learning Index, SLI）量化一个行为在群体中由**社会学习**（vs. 独立创新）贡献的比例：

$$
\text{SLI} = \rho_{\text{sync}} - \rho_{\text{innov}}
$$

其中：
- $\rho_{\text{sync}}$ = 个体间行为同步率（共同掌握该行为的个体对 / 总个体对）
- $\rho_{\text{innov}}$ = **独立创新 baseline**（假设无社会学习下的期望同步率，由环境刺激 + 个体基础学习率拟合）

> **v0.2 修正说明**（2026-04-18）：v0.1 版本只用 $\rho_{\text{sync}}$ 作 SLI，在高密度鸦群（城市中心）下会系统性高估社会学习贡献（因为高密度必然同步）。减去 baseline 是必要修正。详见 [[_Governance/CHANGELOG]] v0.1.3.2 条目的 Q3 三要素执行记录。

## 取值范围

- SLI ∈ $[-1, 1]$
- SLI > 0 → 存在显著社会学习
- SLI ≈ 0 → 独立创新主导
- SLI < 0 → 群体对该行为有"反学习"压力（罕见，待建 [[03-Zettelkasten/思考-反学习压力]] seedling）

## 边界与假设

**适用**：
- 群体规模 n ≥ 20
- 观测时窗 ≥ 12 个月（覆盖完整繁殖季）
- 个体可识别（ring band / 羽色标记 / ML 再识别）

**不适用**：
- 短时窗抽样
- 单个体行为（n=1 无群体比较基础）
